# Juya AI Daily

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This is a script package for Miyu. It provides one tool, `juya_daily`, which reads the text of one day's issue of [Juya AI Daily](https://daily.juya.uk). By default it gives the `概览` (overview) of the newest issue, and you can fetch the other sections (`要闻`, `开发生态`, `模型发布` and so on) with `section`.

## Parameters

The tool takes the following parameters:

| Parameter | Description |
|---|---|
| `date` | `YYYY-MM-DD`, or `today` / `yesterday` (Beijing time). When it is left out, the newest issue is used |
| `section` | The section name (the end of the output lists the sections in this issue); `all` means the whole issue. The default is `概览` |
| `max_chars` | The maximum number of characters to keep, 200–20000, default 6000 |
| `format` | `md` (default) or `json` |

## Notes

This section explains caching, length and when the report comes out.

- The tool uses only the Python standard library. The issue index is cached for 30 minutes; issue text is cached by date, the text of the last two days is fetched again after 6 hours, and older issues are kept for good. The cache is kept in `MIYU_CACHE_DIR`.
- The full text of one issue is a little over ten thousand tokens, so by default the tool only gives the overview; when you need details, fetch them section by section.
- The report usually comes out between 9 and 11 a.m. Beijing time, and if you ask for today's issue before then, the tool says there is no such issue yet.
