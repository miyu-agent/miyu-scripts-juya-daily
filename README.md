# 橘鸦AI早报

Miyu 脚本包，带一件工具 `juya_daily`：读 [橘鸦AI早报](https://daily.juya.uk) 某一天的正文。默认给最新一期的「概览」，其余小节（要闻、开发生态、模型发布……）按 `section` 取。

## 参数

| 参数 | 说明 |
|---|---|
| `date` | `YYYY-MM-DD`，或 `today` / `yesterday`（北京时间）。不写是最新一期 |
| `section` | 小节名（输出末尾列着这一期有哪些），`all` 是全文。默认 `概览` |
| `max_chars` | 截到多少字，200–20000，默认 6000 |
| `format` | `md`（默认）或 `json` |

## 注意

- 只用 Python 标准库。期号索引缓存 30 分钟；正文按日期缓存，最近两天的 6 小时后重取，更早的一直留着。缓存放在 `MIYU_SCRIPT_CACHE_DIR`。
- 一期全文约一万多 token，默认只给概览；要细节时按小节取。
- 早报一般北京时间 9 点到 11 点之间出，在那之前查「今天」会说没有。
