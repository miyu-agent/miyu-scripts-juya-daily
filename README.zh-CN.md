# 橘鸦 AI 早报

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

这是 Miyu 的一个脚本软件包，提供一件工具 `juya_daily`，用来读取 [橘鸦 AI 早报](https://daily.juya.uk) 某一天的正文。它默认给出最新一期的 `概览`，其余小节（`要闻`、`开发生态`、`模型发布`……）可以用 `section` 获取。

## 参数

这件工具接受下面这些参数：

| 参数 | 说明 |
|---|---|
| `date` | `YYYY-MM-DD`，或者 `today` / `yesterday`（北京时间）。不填写时取最新一期 |
| `section` | 小节名（输出的末尾列出了这一期有哪些小节），`all` 表示全文。默认是 `概览` |
| `max_chars` | 截取的最多字数，200–20000，默认 6000 |
| `format` | `md`（默认）或者 `json` |

## 注意

这一节说明缓存、篇幅和早报的发布时间。

- 工具只使用 Python 标准库。期号索引缓存 30 分钟；正文按日期缓存，最近两天的正文在 6 小时后重新获取，更早的一直保留。缓存放在 `MIYU_CACHE_DIR` 里。
- 一期的全文大约有一万多 Token，所以工具默认只给出概览；需要细节时，按小节获取即可。
- 早报一般在北京时间 9 点到 11 点之间发布，在那之前查询今天的早报，工具会提示没有这一期。
